# Lubb — AI-Powered Verbal Analogies Tool

Lubb is a bilingual web application designed to help users solve and practice verbal analogy questions in Arabic and English.

It was developed as part of my graduation project, **“Can Machines Think Like Us? The Ability of Large Language Models to Pass Verbal Analogical Reasoning in Aptitude Tests.”**

## Features

- Arabic and English interfaces
- Verbal analogy solver with AI-generated explanations
- Timed quiz mode with multiple difficulty levels
- Adjustable number of questions
- Score tracking and instant feedback
- Support for GPT-4o and DeepSeek models

## Tech Stack

- HTML
- CSS
- JavaScript
- GPT-4o API
- DeepSeek API
